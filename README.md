# Redução de Custos em Farmácias com AWS

Projeto prático desenvolvido como parte do bootcamp da [DIO (Digital Innovation One)](https://www.dio.me/), no desafio **"Redução dos Custos em Farmácias com AWS"**.

## Objetivo

Conceber e projetar uma plataforma virtual para uma farmácia fictícia (Abstergo Industries) utilizando a infraestrutura da AWS, com foco na **redução de custos imediatos** por meio da adoção de 3 serviços cloud.

## Serviços AWS Implementados

| # | Serviço | Foco |
|---|---------|------|
| 1 | Amazon S3 | Armazenamento de baixo custo |
| 2 | Amazon EC2 + Auto Scaling | Infraestrutura elástica sob demanda |
| 3 | Amazon RDS | Banco de dados gerenciado |
